## Anti-Patterns Verdict

**LLM assessment**: AI 슬롭 테스트는 통과 — 균일 카드 그리드 없음, 아이보리 배경 없음, 대문자 eyebrow 없음. 편집형 위계(#1 히어로 카드, 순위 번호)가 인스타그램 피드와 차별화된다. 단 카테고리 칩의 backdrop-filter glass 사용은 "glassmorphism as default" 금지 규칙과 충돌한다 — 기능적 맥락이 있지만 경계선상.

**Deterministic scan**: 0건. 코드 레벨 안티패턴 감지 없음.

**Visual overlays**: 브라우저 자동화 불가 — 스캔 기반 리뷰로 진행.

## Overall Impression

현재 홈 화면은 "거리 기반 맛집 발견" 하나는 잘 만들어졌다. 편집형 위계, 탱저린 포인트, 피처드 카드의 강렬함은 살아있다. 문제는 **구/군 단위 탐색 레이어가 아예 없어서**, 이 기능을 추가하려면 현재 구조로는 어떻게도 자연스럽게 붙일 수 없다는 것이다. 헤드라인도 "가까운 맛집"에 고정돼 있어 지역 모드에서 쓰기 어렵다.

---

## What's Working

**1. 편집형 위계** — #1 피처드 히어로 카드 + 순위 번호 리스트가 균일 카드 그리드를 탈피. 시각 무게 변화가 명확하다.

**2. 탱저린 포인트 사용** — 거리, 상위 순위, 활성 칩에만 색이 들어간다. Action-Only Color Rule 준수.

**3. 위치 상태 코뮤니케이션** — 찾는 중 레이블, 폴백 레이블, 스켈레톤이 세 가지 상태를 모두 처리.

## Priority Issues

**[P1] 지역별 탐색 진입점 없음**
- 현재 화면에는 구/군 선택 UI가 전혀 없다. 카테고리 칩만 있어, 사용자가 "해운대구 맛집"을 보고 싶어도 경로가 없다.
- 앱 목표("부산 지역별 맛집 탐색")와 구조가 충돌. 이 기능을 나중에 붙이려면 레이아웃 전체를 다시 열어야 한다.
- **Fix**: "내 주변 / 지역별" 세그먼트 컨트롤을 헤더 바로 아래 배치. 지역별 모드는 구/군 선택기 바텀시트로 연결.
- **Command**: `/impeccable craft 구/군 탐색 모드 스위처 + 지역 선택기`

**[P1] 헤드라인·피처드 태그가 위치 모드에 고착**
- "지금 부산, 가까운 맛집", "가장 가까워요 · 320m" — 지역 모드에서는 의미가 없다.
- 지역 모드에서 #1을 어떤 기준(평점? 후기수?)으로 피처링할지도 정의되지 않았다.
- **Fix**: 모드에 따라 헤드라인("지금 부산, 가까운" → "해운대구 맛집"), 피처드 태그("가장 가까워요" → "이 지역 인기") 동적 교체. 지역 모드 랭킹 기준 = rating × log(reviewCount+1).
- **Command**: `/impeccable craft`

**[P2] 지역 필터(16개 구/군)와 카테고리 필터의 충돌**
- 카테고리 칩 방식으로 지역도 추가하면 칩이 22개 이상 — 스크롤하면 보이지 않는 항목은 존재하지 않는 것과 같다.
- **Fix**: 지역은 칩이 아닌 드롭다운/바텀시트 패턴("해운대구 ▾"). 카테고리 칩은 현행 유지.
- **Command**: `/impeccable shape`

**[P2] 리스트 아이템 메타데이터 과밀**
- 한 행에 평점·후기수·카테고리·거리·주소 = 5가지. 주소는 행정동 단위라 지역별 모드에서는 오히려 중복 정보.
- **Fix**: 지역 모드에서는 주소 대신 거리 제거(무의미하므로), 평점+후기수+카테고리만 표시. 모드에 따라 메타 행 구성 변경.
- **Command**: `/impeccable layout`

**[P3] "부산 도심 기준" 카피**
- 위치 실패 폴백 레이블. "도심"은 행정 단어라 사용자가 직관적으로 읽기 어렵다.
- **Fix**: "부산 중심가 기준" 또는 "위치 없이 보기".
- **Command**: `/impeccable clarify`

## Persona Red Flags

**Casey (Distracted Mobile User)**: 위치 권한을 거부했을 때 "부산 도심 기준"으로 자동 폴백하지만 지역 선택 경로가 없어 원하는 동네를 볼 방법이 없다. 카테고리 칩을 여러 개 지나 스크롤해야 모든 선택지를 볼 수 있어 마지막 칩(분식)은 잘 안 눌릴 가능성이 높다.

**Jordan (First-Timer)**: "지역별 보기"라는 기능이 있다는 힌트가 전혀 없다. 위치를 켜지 않으면 왜 "부산 도심 기준"이 되는지 설명 없음. 상단 "위치 켜고 가까운 곳 보기" 레이블이 버튼임을 알아보기 어려울 수 있음(스타일이 버튼보다 배지에 가까움).

**eatBusan 탐색자 ("민준")**: 부산 출신 또는 여행자로 특정 구(해운대, 서면, 광안리)를 목적지로 정하고 앱을 켠다. 현재 화면에서 목적지 구를 지정할 방법이 없어 위치 기반 결과만 보게 된다. 목적지가 현재 위치와 다를 때 앱이 전혀 도움이 안 된다.

## Minor Observations

- CategoryChips의 backdrop-filter glass — 앰비언트 배경이 있어 완전한 glassmorphism은 아니지만, 실용적 이유 없이 blur를 쓰는 수준에 가깝다. 배경이 단색으로 변하면 blur가 의미를 잃는다. 흰 칩 + 탱저린 active로 단순화하는 편이 안전.
- PlaceFeaturedCard의 `clamp(24px, 7vw, 30px)` — 360px 뷰포트에서 25.2px, 430px에서 30.1px. 일관성을 위해 `clamp(22px, 6vw, 30px)` 검토.
- 피처드 카드 hover transform 없음 — PlaceListItem은 `translateY(-2px)` hover가 있지만 피처드 카드는 active(scale 0.985)만 있다. 데스크톱에서 hover가 없으면 클릭 가능한지 불분명.
