# Design System (eatBusan)

> 디자인 일관성의 단일 기준. 색·간격·폰트·컴포넌트 사용 규칙을 여기서 정의한다.
> **토큰 값의 1차 출처는 코드**(`src/app/vuetify.js`, `src/style.css`)다. 이 문서는 그 값을
> 요약하고 "언제 무엇을 쓰는지" 규칙을 정한다. 값이 코드와 달라지면 코드를 기준으로 이 문서를 고친다.
>
> 코드에서 색상값/픽셀을 **하드코딩하지 말고** 아래 토큰(Vuetify 테마 변수 / CSS 변수)을 쓴다.

---

## 0. 컨셉 한 줄

부산 맛집 후기를 **사진 중심**으로 보고 남기는 **모바일 웹앱**. 톤은 **트렌디·소셜·로컬**.
색은 **딥 가넷(와인·자두)** 으로 행동·식욕을 잡고, **허니 골드**로 포인트, **로즈**로 좋아요를 찍는다.
(과거의 바다 블루/주황 탠저린 안은 폐기됨 — 주황은 '테이블링' 등과 겹쳐 의도적으로 뺐다.)

## 1. 컬러 토큰 (Vuetify theme)

`src/app/vuetify.js`에 등록돼 있다. 컴포넌트에선 `color="primary"`처럼 **이름으로만** 참조한다.

| 토큰 | 값 | 용도 |
|------|------|------|
| `primary` | `#B0234A` 가넷 | 메인 행동(작성·등록·확인), 현재 선택, 강조 |
| `primary-darken-1` | `#8E1B3A` | primary hover/pressed, 틴트 위 텍스트 |
| `secondary` | `#FF3D6A` 로즈 | 좋아요/하트 (primary와 구분되는 반응 색) |
| `secondary-darken-1` | `#E62F58` | secondary hover |
| `warning` | `#E8A53D` 허니 골드 | 별점, 포인트 강조 아이콘 |
| `success` | `#15B86B` | 성공 상태 |
| `error` | `#DC2626` | 에러 상태·검증 실패 |
| `info` | `#2C8C8C` | 정보/지도·위치용 쿨 액센트 (소량) |
| `background` | `#FAF6F2` | 앱 본문 배경(따뜻한 아이보리, 가넷으로 미세 틴트) |
| `surface` | `#FFFFFF` | 카드·시트·입력 표면 |
| `on-surface` / `on-background` | `#211A17` 잉크 | 본문·제목 텍스트 |
| `on-primary` / `on-secondary` | `#FFFFFF` | 가넷·로즈 위 텍스트 |

### CSS 변수 (`src/style.css` — Vuetify 밖 커스텀 CSS에서 사용)

```css
--brand: #b0234a;          /* 가넷 = primary */
--brand-deep: #8e1b3a;
--brand-tint: rgba(176, 35, 74, 0.10);        /* 가넷 10% — 칩/pill 배경 */
--brand-tint-strong: rgba(176, 35, 74, 0.16); /* 가넷 16% — hover */
--honey: #e8a53d;
--rose: #ff3d6a;
--ink: #211a17;
```

### 색 사용 규칙 (중요)

- **Action-Only Color Rule.** 가넷·로즈·허니는 **행동·현재 선택·상태·별점**에만. 배경을 칠하거나 섹션을 나누려고 색을 뿌리지 않는다. 큰 색면이 필요하면 그 자리는 **사진**이 차지한다.
- **대비(Contrast).** 본문 텍스트는 배경 대비 ≥4.5:1. 잉크(`#211A17`)는 아이보리/흰 배경에서 안전.
  - ⚠️ **허니(`#E8A53D`)·로즈(`#FF3D6A`)는 흰 배경에서 본문 텍스트로 쓰지 않는다**(대비 미달). 아이콘·별점·큰 라벨·채움 배지에만.
  - 가넷 틴트(`--brand-tint`) 위 텍스트는 **`--brand-deep`(`#8E1B3A`)** 로(예: 위치 pill).
  - 흰 텍스트는 가넷/로즈 **채움** 위에서만. 옅은 색 위 흰 텍스트 ❌.
- **색만으로 정보 전달 ❌.** 좋아요·에러 등은 아이콘/형태/텍스트를 함께.

## 2. 타이포그래피

폰트: **Pretendard** 1종(`--app-font`, 폴백 system-ui). Roboto·기타 서체 혼용 ❌. 위계는 **크기·굵기**로만.

| 용도 | Vuetify 클래스 / 값 | 비고 |
|------|------|------|
| 페이지 제목 | `text-h4` 굵게 또는 `font-size: clamp(26px,8vw,34px); font-weight:800` | 한 화면에 하나 |
| 섹션 제목 | `text-h6` (≈20px, 700) | |
| 카드/항목 제목 | 16~18px / 700~800 | `letter-spacing: -0.03em` |
| 본문 | `text-body-1` (16px/1.5) | 산문 65~75ch 이내 |
| 보조/캡션 | `text-body-2`·`text-caption text-medium-emphasis` | `#211A17` 투명도로 |

- 제목 letter-spacing 바닥: **≥ -0.045em** (그보다 좁히면 글자 붙음).
- 대문자 문장 ❌. 대문자는 짧은 라벨/배지(≤4단어)만.

---

## 3. 간격 (Spacing)

Vuetify spacing 유틸리티 우선(`pa-4`, `ma-2`, `gap`). 1단위 = 4px. 커스텀 CSS면 4의 배수.

| 용도 | 값 |
|------|-----|
| 컴포넌트 내부 패딩 | `pa-4` (16px) / 카드 16~18px |
| 카드 간 간격 | 8~12px |
| 섹션 간 간격 | 18~24px |

임의 `margin: 13px` 같은 비격자 값 ❌. 리듬을 위해 간격은 의도적으로 변주한다(다 같은 간격 금지).

---

## 4. 모서리·그림자·표면

- **모서리**: 버튼/입력 `rounded="lg"`. 카드 16~22px, 시트 상단 24px, 히어로 24px, 칩/pill 9999px.
- **표면은 기본 플랫.** 상시 머터리얼 드롭섀도(`elevation`) ❌(데모 룩). 깊이는 1px 테두리·배경 단차로.
- **그림자는 상태 응답으로만**: hover lift, 떠오른 시트/메뉴. 토큰: `--depth-1`(카드), `--depth-2`(오버레이).
- **글래스(backdrop-filter)는 셸 크롬(상단바·하단탭)에만.** 장식용 글래스 카드 ❌.

---

## 5. 레이아웃 — 모바일 웹앱(폰 셸)

- 앱은 **iPhone 가로세로비(`aspect-ratio: 9 / 19.5`) 디바이스 셸**이다. **페이지 높이(100dvh)를 꽉 채우고
  폭은 그 비율로 derive**된다(고정 px 폭 아님). 단 **`min-width: 400px`** 로 실제 아이폰 폭 이하로 좁아지지 않게 막는다(낮은 화면에서 리스트 행 깨짐 방지). 데스크탑에선 바깥이 중립 배경으로 빠지고 안쪽이 세로 폰처럼 보인다.
  ⚠️ 리스트 행 등 가로 밀도가 높은 컴포넌트는 **400px 셸 폭에서 깨지지 않게** 만든다: 한 줄 유지 + `min-width:0` + ellipsis(예: `PlaceListItem`의 rating/meta 행), 썸네일·간격은 작게.
  모바일(<600px)에선 전체화면. 셸은 내부 스크롤(`.viewport`)이고 상단바·하단탭은 셸 안에 고정. 골격은 `src/App.vue`(`.device`/`.appbar`/`.viewport`/`.bottomnav`).
- **새 페이지는 셸 폭 안에서 1열로 쌓는다.** `<v-container><v-row><v-col>` 데스크탑 그리드로 넓게 펼치지 않는다.
- 한 손 조작: 터치 타깃 **≥44px**, 주요 행동은 엄지 도달 범위(하단) 우선.
- 상단바: 좌측 로고(홈), 우측 **로그인** 버튼(`/login`). 하단 탭: **홈 / 둘러보기 / 마이페이지**. 임의로 늘리지 않는다.
- 로그인 등 전체화면 페이지는 라우트 `meta: { chrome: false }`로 상단바·하단탭을 숨긴다.

## 6. 컴포넌트 사용 규칙

- 버튼 → `<v-btn>` (직접 `<button>` 스타일링은 셸·세그먼트 등 특수 컨트롤에 한함, 색은 토큰)
- 입력 → `<v-text-field variant="solo-filled">` / `<v-textarea>`
- 다이얼로그/시트 → `<v-dialog>` / `<v-bottom-sheet>` (모바일은 바텀시트 우선, 모달 남발 ❌). **오버레이는 반드시 `attach="#app-shell" contained`** — 안 그러면 셸 폭을 무시하고 화면 전체로 퍼진다(UI_KIT 참고)
- 로딩 → 콘텐츠 자리엔 **스켈레톤**(`<v-skeleton-loader>`), 짧은 액션에만 `<v-progress-circular>`
- 빈 상태 → "없음"이 아니라 **다음 행동을 가르치는** 카피 + 버튼
- 반복되는 조합·이미 있는 패턴은 새로 만들지 말고 **[UI_KIT.md](./UI_KIT.md)** 의 것을 재사용한다

상태 커버리지: 모든 인터랙티브 컴포넌트는 default·hover·focus·active·disabled·(필요시 loading/error)를 갖춘다.

## 7. 모션

- 상태 전환 **150~250ms**, ease-out 계열. 바운스/엘라스틱 ❌. 레이아웃 속성 애니메이션 지양.
- `@media (prefers-reduced-motion: reduce)` 대안(크로스페이드/즉시 전환) **필수**.
- 페이지 로드용 연출 시퀀스 ❌(앱은 task로 바로 진입). 리스트 stagger 정도는 허용.

---

## 8. 금지 (AI 슬롭 방지)

`PRODUCT.md`의 Anti-references + 다음은 **항상 금지**:
사이드 스트라이프 보더(1px 초과 좌/우 컬러 라인), 그라디언트 텍스트, 장식용 글래스모피즘,
모든 섹션 위 대문자 eyebrow, 똑같은 아이콘+제목+텍스트 카드 그리드 반복, 상시 드롭섀도 카드,
관공서 관광 사이트식 정보 나열, 배너·팝업 범벅, 채도 없는 B2B SaaS 톤.

---

## 9. 변경 절차

색/폰트/간격 토큰을 바꾸려면: ① `src/app/vuetify.js` / `src/style.css` 수정 → ② 이 문서 표 동기화 →
③ PR에 "디자인 토큰 변경" 명시. 토큰은 **팀 합의** 대상. 개별 기능 PR에서 임의로 새 색을 추가하지 않는다.
